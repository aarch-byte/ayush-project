# AYUSH® — The Digital Universe

> "I'm not here to fit into a box. I'm here to explore what's outside it."

## Architecture Overview

- **Framework**: Next.js 14 App Router (React 18 + TypeScript)
- **Styling & Tokens**: Tailwind CSS with custom editorial design tokens
- **Typography**: Space Grotesk (display), Instrument Serif (editorial accents), Inter (body), IBM Plex Mono (metadata)
- **3D & Graphics**: Three.js, React Three Fiber, Drei (prepared in project structure)
- **Animation**: GSAP & ScrollTrigger
- **Icons**: Lucide React

## Design System Tokens

- Primary Background: `#101010`
- Primary Text: `#F2EFE7`
- Signature Accent: `#D8FF3E` (Acid Green)
- Secondary Accent: `#FF674A` (Editorial Coral)
- Muted Grey: `#77766F`
- Surface: `#181818`
